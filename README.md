# صفحة كورسات الأمن السيبراني: apptrainers

صفحة هبوط (Landing Page) ثنائية اللغة. العربي هو الأساس (RTL)، وفي زر للتبديل للإنجليزي. الصفحة HTML/CSS/JS ثابتة، بدون أي build.

## تشغيلها محلياً

```bash
python3 -m http.server 8765 --directory .
# وافتح http://127.0.0.1:8765/   (والإنجليزي: ?lang=en)
```

## هيكل الملفات

| الملف | شو فيه |
|---|---|
| `index.html` | هيكل الصفحة، وكل النصوص العربية مكتوبة فيه كقيم افتراضية (بتشتغل حتى بدون JS) |
| `assets/js/content.js` | **كل النصوص بالعربي والإنجليزي، والمسارات الأربعة، وقائمة الكورسات الـ24.** أي تعديل على المحتوى بصير هون |
| `assets/js/main.js` | تبديل اللغة، فلترة الكورسات، أنيميشن التيرمنال، والتحقق من الفورم وإرساله |
| `assets/css/styles.css` | التصميم كامل. الألوان والخطوط موجودة كمتغيرات بأول الملف |
| `assets/vision-3020-white.svg` | شعار Vision 3020 المستخدم بالهيدر والفوتر وأيقونة التبويب: الأحرف الكحلية صارت بيضاء والأحمر زي ما هو، بخلفية شفافة (نفس ملف مشروع cyber2) |
| `assets/apptrainers-mark-dark.svg`، `assets/apptrainers-logo-light.svg`، `assets/favicon.svg` | شعارات apptrainers القديمة، محفوظة بس ما عادت مستخدمة |

## وضع المسودة (Draft)

`<html ... data-draft>` بـ `index.html` بيشغّل وضع المسودة: **كل قيمة مقترحة إلها خط منقّط أصفر تحتها**، ولما تمرق عليها بالماوس بتطلع «مقترح، بانتظار التأكيد». هدول هنن: الأعمار، وشهادة الإتمام، و«بدون دفع الآن»، و«جلسات مع مدرّبين». الساعات والمختبرات والشهادات صارت من ملف المحتوى اللي بعته العميل، فما عليها علامة. بالكود معلّم عليهم بخاصية `data-proposal`.

لما تتأكدوا من قيمة: عدّلوها، واحذفوا `data-proposal` عنها (عن العنصر نفسه، أو عن الـ`<span>` بنص `content.js`). ولما يصير المحتوى كله حقيقي: شيلوا `data-draft` من وسم `<html>`، والخطوط المنقّطة بتختفي.

## ربط فورم التسجيل بالباك إند (Laravel)

الفورم هلأ بـ**وضع تجريبي**: ما بيبعت إشي، بس بيطبع البيانات بالـ console وبيعرض رسالة النجاح. لتشغيله فعلياً:

1. حط رابط الـ route بـ `data-endpoint`:
   ```html
   <form ... data-form data-endpoint="/register-interest">
   ```
2. ولما تحوّل الصفحة لـ Blade، أضف الـ CSRF بالـ `<head>`، والسكربت بيبعته لحاله كـ `X-CSRF-TOKEN`:
   ```html
   <meta name="csrf-token" content="{{ csrf_token() }}">
   ```
3. الطلب `POST` بصيغة JSON، وهاي الحقول اللي بتوصل:

   | الحقل | ملاحظات |
   |---|---|
   | `name` | إجباري |
   | `phone` | إجباري. الأرقام العربية (٠-٩) بتتحوّل تلقائياً لأرقام إنجليزية |
   | `email` | اختياري |
   | `audience` | `teens` / `beginners` / `students` / `pros` |
   | `guardian_phone` | إجباري بس إذا `audience = teens` |
   | `course` | كود الكورس مثل `RED-201`، أو فاضي يعني «ساعدوني في الاختيار» |
   | `format` | `in-person` / `online` / `any` |
   | `notes` | اختياري |
   | `lang`, `source` | لغة الزائر، ومصدر الطلب (`landing-cyber`) |

   أي رد غير `2xx` بيعرض رسالة خطأ للزائر، وبيقدر يعيد المحاولة. **لازم تعيدوا التحقق من الحقول بالسيرفر** (validation)، لأن التحقق بالمتصفح للتجربة بس.

## محتوى لازم يتأكد أو يتبدّل قبل النشر

كل هاد **محتوى مقترح** وما بيعكس معلومات حقيقية عن apptrainers:

- [x] **المسارات الأربعة والكورسات الـ24** (بـ `content.js`): من ملف المحتوى (PDF) اللي بعته العميل بتاريخ 2026-10-01، والترجمة الإنجليزية مأخوذة منه.
- [ ] **ساعات GRC-301**: فاضية بالملف، فما بتظهر لحد ما توصل.
- [x] **ربط الشهادات بالكورسات** بقسم «هكذا نعلّم»: Security+ ← FND-201، وCEH ← RED-203، وPenTest+ ← RED-301، وCySA+ ← BLU-301 (من أسماء الكورسات بالملف).
- [ ] **برامج اليافعين**: سؤال الأعمار بالأسئلة الشائعة بيذكر «مستكشفو السايبر» و«تحديات CTF للناشئين»، وهدول مش موجودين بقائمة الكورسات الجديدة. ونفس الإشي شريط الإعلان «من المدرسة حتى الاحتراف». قرروا: بتضيفوهم أو بتشيلوا السؤال وبتعدلوا الشريط.
- [ ] **شهادة الإتمام من apptrainers** (الأسئلة الشائعة + «رحلتك خطوة بخطوة»): تأكدوا إنكم فعلاً بتصدروها.
- [ ] **«جلسات مع مدرّبين»** و**«نساعدك في تجهيز المختبر بأول جلسة»**: تأكدوا من طريقة التدريب.
- [ ] **طريقة التدريب والمدينة**: الصفحة ما بتحدد حضوري ولا أونلاين، لأنها لسا مش محسومة. لما تنحسم عدّلوا جواب السؤال «هل التدريب حضوري أم عن بُعد؟».
- [ ] **آراء المتدربين**: أمثلة بس (شوفوا قسم وضع المسودة).
- [ ] **مثال التيرمنال** بالهيرو ولوحة الـCTF ومخطط الشبكة: أمثلة توضيحية، ومكتوب تحتها إنها أمثلة.
- [ ] **معلومات التواصل وروابط السوشال**: مش موجودة بالفوتر. ضيفوها إذا بدكم.

## ملاحظات تقنية

- **الخطوط** من Google Fonts: Alexandria للعناوين العربية، Readex Pro للنص العربي، Mona Sans للإنجليزي، JetBrains Mono للتيرمنال. للإنتاج بفضّل تستضيفوها على سيرفركم.
- **الألوان**: أحمر الشعار `#EF4050` للعناصر الكبيرة والعلامات. الأزرار أغمق شوي (`#DC2E42`) عشان النص الأبيض عليها يحقق تباين WCAG AA.
- **الاتجاه**: كل المسافات والمواقع مكتوبة بخصائص منطقية (`inset-inline`، `margin-inline`)، فالتصميم بينعكس تلقائياً بين العربي والإنجليزي.
- **الحركة**: التيرمنال بيكتب مرة وحدة لما يبان. ولمن مفعّل عنده «تقليل الحركة» بالنظام، بيطلعله الشكل النهائي مباشرة.
